# DCIT 318 — Assignment 2

Three C# console applications demonstrating OOP concepts:

- **InheritanceOverriding** — Animal base class with Dog and Cat overriding `MakeSound()`.
- **AbstractClasses** — Abstract `Shape` class with `Circle` and `Rectangle` implementing `GetArea()`.
- **Interfaces** — `IMovable` interface implemented by `Car` and `Bicycle`.

Each folder is a standalone console app. Run any one with:

```
cd FolderName
dotnet run
```

Remember to rename this repository to `dcit318-assignment2-ID` (replace ID with your student ID) before pushing, and commit each task folder separately.
